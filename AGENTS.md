# Instrucciones de mantenimiento

- Conservar la configuración local de Eclipse y las funcionalidades existentes.
- Nunca versionar secretos, datos reales, bases, backups, logs o configuración local.
- Mantener contraseñas de usuarios sin hash hasta nueva indicación explícita del propietario.
- Usar ramas para cambios importantes; mantener main estable.
- Verificar cada funcionalidad y preparar commits con mensajes feat:, fix: o docs:.
- Avisar y proponer el push al finalizar; no hacer push automáticamente en cambios futuros.
- No atribuir funcionalidades verificadas en ejecución basándose únicamente en revisión estática.
- Autor y licencia requieren confirmación del propietario.
